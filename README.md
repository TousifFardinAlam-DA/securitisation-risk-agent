# Securitisation Risk Assessment & IFRS 9 Analytics Platform

**Project Code:** 483553A  
**Timeline:** 15 Days | Tech – Data Tech Track  
**Platform:** Microsoft Power BI, Power Query, DAX, Excel  

## Project Overview
An enterprise-grade securitisation analytics and credit risk assessment platform built on assumed banking data from SAP/ERP systems. The platform implements:
- Star Schema dimensional data modeling for auto loan asset-backed securities (ABS).
- IFRS 9 Expected Credit Loss (ECL) multi-stage provisioning ($ECL = PD \times LGD \times EAD$).
- Sequential cash flow waterfall distributions and tranche seniority tracking.
- Macroeconomic stress testing and dynamic "What-If" parameter simulation.
- Institutional investor reporting and rating agency surveillance tapes.
